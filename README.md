# Assistente Inteligente de Atendimento com IA

Projeto desenvolvido em Python que utiliza inteligência artificial generativa para simular um atendimento ao cliente.

## Funcionalidades

- Atendimento interativo pelo terminal.
- Respostas geradas por inteligência artificial.
- Histórico de conversa durante a sessão.
- Tratamento de erros e validação de perguntas.
- Integração com a API Groq.

## Tecnologias utilizadas

- Python
- Groq API
- Python-dotenv
- Git e GitHub

## Como executar

1. Clone o repositório.
2. Crie um ambiente virtual Python.
3. Instale as dependências com `python -m pip install -r requirements.txt`.
4. Crie um arquivo `.env` com a variável `GROQ_API_KEY` e sua própria chave da API.
5. Execute `python main.py`.

## Objetivo

Aplicar conhecimentos de Python, integração com APIs e inteligência artificial generativa no desenvolvimento de uma solução prática de atendimento automatizado.

## Observações

Este projeto é uma simulação educacional. O assistente não possui acesso a pedidos reais, bancos de dados de clientes ou sistemas de lojas.
